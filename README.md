# 🌊 Tide & Timber

Tide & Timber is a small **single-page website** for a fictional coastal field school focused on outdoor learning, shoreline restoration, and connecting people with nature.

## 🌿 About

The website promotes educational experiences by the coast, including:

- Marsh walks
- Dune restoration
- Tide-pool exploration
- Coastal learning sessions
- Shoreline restoration
- Community activities

It has a modern **eco-education and lifestyle** feel, designed to encourage visitors to explore sessions and join upcoming events.

## ✨ Website Sections

- **Hero Section** – Main introduction with call-to-action buttons
- **Why We Do This** – Introduction to the organization's purpose
- **Field Notes** – Blog-style cards featuring coastal observations
- **Learning Sessions** – Educational content using an accordion and image carousel
- **Testimonial** – Visitor experience/quote
- **Footer** – Newsletter email signup
- **Event Modal** – Popup form for joining the next event

## 🎨 Design & Technologies

The website is built using:

- **HTML5** – Page structure
- **CSS3** – Custom styling
- **JavaScript** – Interactive functionality
- **Bootstrap** – Responsive layout and UI components

The design uses a **coastal, earthy aesthetic** with warm colors, natural textures, and editorial-style typography.

## ⚡ JavaScript Interactions

JavaScript provides simple frontend interactions:

- Newsletter signup displays a success message
- Event registration modal displays a success message
- Mobile navigation closes when a navigation link is selected
